### 🔎 About me

I'm a QA Automation Engineer based in Bogotá, Colombia, focused on building **reliable, maintainable test automation** for web and API products. I trained through TripleTen's QA Engineering bootcamp and I'm currently in their career accelerator, sharpening real-world automation skills on live projects.

Before QA, I ran **RaccoonDev**, a low-code/no-code consultancy building products for small businesses. That background shapes how I test today: I care about the *business impact* of a bug, not just whether an assertion passes. I write test plans the way I used to write project scopes — starting from risk, not from tools.

- 🧪 I design test strategies before I write test code — problem, risk, coverage, then automation.
- 🐍 I automate UI flows with **Selenium** and **Playwright** in **Python**, and API contracts with **Postman** and **Pytest**.
- 🗄️ I validate data integrity with **SQL**, not just the UI layer.
- ☁️ I'm comfortable working across **GCP**, **Docker**, and **FastAPI**-based services when testing needs to reach the backend.
- 📋 I track requirements and bugs in **Jira**, and I write test evidence that a non-technical stakeholder can actually read.
- 🌎 Open to remote QA Automation roles across LATAM and internationally.
